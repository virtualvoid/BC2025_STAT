# Smerníky a dynamické údaje v jazyku C++

## Úvod

V jazyku **C++** sú smerníky a dynamická pamäť veľmi dôležité, pretože umožňujú vytvárať objekty a polia počas behu programu.

Oproti jazyku C má C++ navyše:

- triedy,
- konštruktory,
- deštruktory,
- objekty vytvárané pomocou `new`,
- objekty rušené pomocou `delete`,
- virtuálne funkcie,
- polymorfizmus.

V modernom C++ sa často odporúča používať kontajnery ako `std::vector` a inteligentné smerníky ako `std::unique_ptr`, ale na pochopenie základov je potrebné rozumieť aj obyčajným smerníkom a dynamickej pamäti.

---

## 1. Typ smerník

Smerník je premenná, ktorá obsahuje **adresu inej premennej alebo objektu v pamäti**.

Bežná premenná:

```cpp
int x = 10;
```

Smerník na `int`:

```cpp
int *p = &x;
```

Tu platí:

- `x` obsahuje hodnotu `10`,
- `&x` je adresa premennej `x`,
- `p` obsahuje adresu premennej `x`,
- `*p` znamená hodnota, na ktorú smerník ukazuje.

---

## Operátor `&`

Operátor `&` slúži na získanie adresy premennej.

```cpp
int x = 10;
int *p = &x;
```

---

## Operátor `*`

Operátor `*` pri smerníku slúži na dereferencovanie, teda na prístup k hodnote na danej adrese.

```cpp
#include <iostream>

int main()
{
    int x = 10;
    int *p = &x;

    std::cout << "x = " << x << std::endl;
    std::cout << "*p = " << *p << std::endl;

    return 0;
}
```

Výstup:

```text
x = 10
*p = 10
```

---

## Zmena hodnoty cez smerník

```cpp
#include <iostream>

int main()
{
    int x = 10;
    int *p = &x;

    *p = 25;

    std::cout << "x = " << x << std::endl;

    return 0;
}
```

Výstup:

```text
x = 25
```

Hodnota premennej `x` sa zmenila cez smerník `p`.

---

## Smerník a `nullptr`

V C++ sa pre smerník, ktorý nikam neukazuje, používa hodnota `nullptr`.

```cpp
int *p = nullptr;
```

Pred použitím smerníka je dobré overiť, či nie je `nullptr`.

```cpp
if (p != nullptr)
{
    std::cout << *p << std::endl;
}
```

Nesprávne:

```cpp
int *p = nullptr;
std::cout << *p << std::endl;
```

Dereferencovanie `nullptr` je chyba a môže spôsobiť pád programu.

---

## 2. Pojem dynamického údaju

Dynamický údaj je údaj alebo objekt, ktorý vzniká počas behu programu v dynamickej pamäti.

Dynamická pamäť sa používa vtedy, keď:

- dopredu nevieme počet prvkov,
- objekt má existovať dlhšie ako lokálna premenná,
- potrebujeme vytvárať objekty podľa aktuálnej situácie v programe,
- pracujeme s polymorfizmom.

Bežná lokálna premenná:

```cpp
int x = 10;
```

Dynamicky vytvorená premenná:

```cpp
int *p = new int;
```

Dynamický údaj treba neskôr uvoľniť:

```cpp
delete p;
p = nullptr;
```

---

## 3. Prideľovanie dynamickej pamäte

V C++ sa dynamická pamäť prideľuje najmä operátorom:

```cpp
new
```

Na uvoľnenie sa používa:

```cpp
delete
```

---

## Dynamické vytvorenie jedného čísla

```cpp
#include <iostream>

int main()
{
    int *p = new int;

    *p = 42;

    std::cout << "Hodnota: " << *p << std::endl;

    delete p;
    p = nullptr;

    return 0;
}
```

Výstup:

```text
Hodnota: 42
```

---

## Inicializácia dynamickej premennej

Dynamickú premennú možno inicializovať priamo.

```cpp
int *p = new int(42);
```

Celý príklad:

```cpp
#include <iostream>

int main()
{
    int *p = new int(42);

    std::cout << *p << std::endl;

    delete p;
    p = nullptr;

    return 0;
}
```

Výstup:

```text
42
```

---

## Dynamický objekt

Ak vytvárame objekt triedy, použijeme tiež `new`.

```cpp
#include <iostream>
#include <string>

class Person
{
public:
    std::string name;

    Person(const std::string& name)
    {
        this->name = name;
    }

    void print()
    {
        std::cout << "Meno: " << name << std::endl;
    }
};

int main()
{
    Person *p = new Person("Juraj");

    p->print();

    delete p;
    p = nullptr;

    return 0;
}
```

Výstup:

```text
Meno: Juraj
```

Pri smerníku na objekt sa k členom pristupuje pomocou operátora `->`.

```cpp
p->print();
```

Tento zápis je skrátená forma:

```cpp
(*p).print();
```

---

## 4. Uvoľňovanie dynamickej pamäte

Pamäť pridelená cez `new` sa uvoľňuje cez `delete`.

```cpp
int *p = new int(10);

delete p;
p = nullptr;
```

Pamäť pridelená cez `new[]` sa musí uvoľniť cez `delete[]`.

```cpp
int *array = new int[10];

delete[] array;
array = nullptr;
```

---

## Dôležité pravidlo

| Alokácia | Uvoľnenie |
|---|---|
| `new` | `delete` |
| `new[]` | `delete[]` |

Nesprávne:

```cpp
int *array = new int[10];

delete array;
```

Správne:

```cpp
int *array = new int[10];

delete[] array;
```

Pri nesprávnom použití môže vzniknúť nedefinované správanie.

---

## 5. Diery v pamäti

Diera v pamäti, často nazývaná **memory leak**, vznikne vtedy, keď program pridelí dynamickú pamäť, ale neuvoľní ju.

Nesprávne:

```cpp
int *p = new int(10);

return 0;
```

Pamäť bola pridelená, ale nebola uvoľnená.

Správne:

```cpp
int *p = new int(10);

delete p;
p = nullptr;
```

---

## Strata adresy dynamickej pamäte

Memory leak vznikne aj vtedy, keď stratíme adresu pridelenej pamäte.

Nesprávne:

```cpp
int *p = new int(10);

p = nullptr;
```

Adresa pôvodne pridelenej pamäte sa stratila, takže ju už nevieme uvoľniť.

Správne:

```cpp
int *p = new int(10);

delete p;
p = nullptr;
```

---

## Prečo sú diery v pamäti problém

Ak program opakovane prideľuje pamäť a neuvoľňuje ju, spotreba pamäte rastie.

Môže to viesť k:

- spomaleniu programu,
- vyčerpaniu pamäte,
- pádu programu,
- nestabilite aplikácie.

---

## 6. Vystrčené smerníky

Vystrčený smerník, často označovaný ako **dangling pointer**, je smerník, ktorý ukazuje na pamäť, ktorá už nie je platná.

Typicky vznikne po `delete`.

Nesprávne:

```cpp
#include <iostream>

int main()
{
    int *p = new int(10);

    delete p;

    std::cout << *p << std::endl;

    return 0;
}
```

Po `delete p;` už smerník `p` ukazuje na uvoľnenú pamäť.

Použitie `*p` je chyba.

---

## Oprava vystrčeného smerníka

```cpp
#include <iostream>

int main()
{
    int *p = new int(10);

    delete p;
    p = nullptr;

    if (p != nullptr)
    {
        std::cout << *p << std::endl;
    }

    return 0;
}
```

Po uvoľnení pamäte nastavíme smerník na `nullptr`.

---

## Vystrčený smerník na lokálnu premennú

Vystrčený smerník môže vzniknúť aj vtedy, keď funkcia vráti adresu lokálnej premennej.

Nesprávne:

```cpp
int* createNumber()
{
    int x = 10;

    return &x;
}
```

Premenná `x` zanikne po skončení funkcie, takže vrátená adresa je neplatná.

Správnejšie:

```cpp
int* createNumber()
{
    return new int(10);
}
```

Použitie:

```cpp
#include <iostream>

int* createNumber()
{
    return new int(10);
}

int main()
{
    int *number = createNumber();

    std::cout << *number << std::endl;

    delete number;
    number = nullptr;

    return 0;
}
```

Výstup:

```text
10
```

---

## 7. Konštruktory dynamických objektov

Konštruktor je špeciálna metóda triedy, ktorá sa zavolá pri vytvorení objektu.

Ak vytvárame objekt dynamicky pomocou `new`, konštruktor sa zavolá automaticky.

```cpp
#include <iostream>

class Test
{
public:
    Test()
    {
        std::cout << "Konstruktor bol zavolany." << std::endl;
    }
};

int main()
{
    Test *t = new Test();

    delete t;
    t = nullptr;

    return 0;
}
```

Výstup:

```text
Konstruktor bol zavolany.
```

---

## Konštruktor s parametrom

```cpp
#include <iostream>
#include <string>

class Person
{
private:
    std::string name;

public:
    Person(const std::string& name)
    {
        this->name = name;
        std::cout << "Vytvaram osobu: " << name << std::endl;
    }

    void print()
    {
        std::cout << "Meno: " << name << std::endl;
    }
};

int main()
{
    Person *person = new Person("Juraj");

    person->print();

    delete person;
    person = nullptr;

    return 0;
}
```

Výstup:

```text
Vytvaram osobu: Juraj
Meno: Juraj
```

---

## 8. Deštruktory dynamických objektov

Deštruktor je špeciálna metóda triedy, ktorá sa zavolá pri zániku objektu.

Pri dynamickom objekte sa deštruktor zavolá pri `delete`.

```cpp
#include <iostream>

class Test
{
public:
    Test()
    {
        std::cout << "Konstruktor." << std::endl;
    }

    ~Test()
    {
        std::cout << "Destruktor." << std::endl;
    }
};

int main()
{
    Test *t = new Test();

    delete t;
    t = nullptr;

    return 0;
}
```

Výstup:

```text
Konstruktor.
Destruktor.
```

---

## Prečo je deštruktor dôležitý

Deštruktor sa používa na uvoľnenie prostriedkov, napríklad:

- dynamickej pamäte,
- otvorených súborov,
- sieťových spojení,
- iných systémových zdrojov.

Príklad triedy, ktorá si sama spravuje dynamickú pamäť:

```cpp
#include <iostream>

class Number
{
private:
    int *value;

public:
    Number(int number)
    {
        value = new int(number);
    }

    ~Number()
    {
        delete value;
        value = nullptr;
    }

    void print()
    {
        std::cout << *value << std::endl;
    }
};

int main()
{
    Number *n = new Number(100);

    n->print();

    delete n;
    n = nullptr;

    return 0;
}
```

Výstup:

```text
100
```

V tomto príklade:

- `new Number(100)` vytvorí dynamický objekt,
- konštruktor triedy `Number` pridelí pamäť pre `int`,
- `delete n` zavolá deštruktor triedy `Number`,
- deštruktor uvoľní vnútornú dynamickú pamäť.

---

## 9. Dynamické pole

Dynamické pole je pole, ktorého veľkosť sa určí počas behu programu.

Vytvorenie dynamického poľa:

```cpp
int *array = new int[5];
```

Uvoľnenie dynamického poľa:

```cpp
delete[] array;
array = nullptr;
```

---

## Príklad dynamického poľa

```cpp
#include <iostream>

int main()
{
    int size;

    std::cout << "Zadaj pocet prvkov: ";
    std::cin >> size;

    if (size <= 0)
    {
        std::cout << "Neplatna velkost." << std::endl;
        return 1;
    }

    int *array = new int[size];

    for (int i = 0; i < size; i++)
    {
        array[i] = i + 1;
    }

    for (int i = 0; i < size; i++)
    {
        std::cout << array[i] << " ";
    }

    std::cout << std::endl;

    delete[] array;
    array = nullptr;

    return 0;
}
```

Možný výstup:

```text
Zadaj pocet prvkov: 5
1 2 3 4 5
```

---

## Dynamické pole objektov

Pri poli objektov sa zavolá konštruktor pre každý prvok poľa.

```cpp
#include <iostream>

class Item
{
public:
    Item()
    {
        std::cout << "Konstruktor Item" << std::endl;
    }

    ~Item()
    {
        std::cout << "Destruktor Item" << std::endl;
    }
};

int main()
{
    Item *items = new Item[3];

    delete[] items;
    items = nullptr;

    return 0;
}
```

Výstup:

```text
Konstruktor Item
Konstruktor Item
Konstruktor Item
Destruktor Item
Destruktor Item
Destruktor Item
```

Pri `delete[]` sa zavolá deštruktor pre každý prvok poľa.

---

## 10. Dynamické pole ako trieda

Dynamické pole môžeme zabaliť do vlastnej triedy.

Takáto trieda môže:

- vytvoriť dynamické pole v konštruktore,
- uvoľniť pole v deštruktore,
- poskytovať metódy na prístup k prvkom,
- kontrolovať hranice poľa.

---

## Jednoduchá trieda dynamického poľa

```cpp
#include <iostream>

class IntArray
{
private:
    int *data;
    int size;

public:
    IntArray(int size)
    {
        this->size = size;
        data = new int[size];

        for (int i = 0; i < size; i++)
        {
            data[i] = 0;
        }
    }

    ~IntArray()
    {
        delete[] data;
        data = nullptr;
    }

    int getSize()
    {
        return size;
    }

    void set(int index, int value)
    {
        if (index >= 0 && index < size)
        {
            data[index] = value;
        }
    }

    int get(int index)
    {
        if (index >= 0 && index < size)
        {
            return data[index];
        }

        return 0;
    }
};

int main()
{
    IntArray array(5);

    array.set(0, 10);
    array.set(1, 20);

    for (int i = 0; i < array.getSize(); i++)
    {
        std::cout << array.get(i) << " ";
    }

    std::cout << std::endl;

    return 0;
}
```

Výstup:

```text
10 20 0 0 0
```

Tu nie je potrebné volať `delete[]` v `main`, pretože to urobí deštruktor triedy `IntArray`.

---

## Problém kopírovania dynamického poľa

Ak trieda obsahuje dynamickú pamäť, treba myslieť na kopírovanie.

Napríklad toto je problémové:

```cpp
IntArray a(5);
IntArray b = a;
```

Ak trieda nemá vlastný kopírovací konštruktor, oba objekty môžu ukazovať na tú istú dynamickú pamäť.

Potom by oba deštruktory zavolali `delete[]` na tú istú adresu, čo je chyba.

---

## Pravidlo troch

Ak trieda vlastní dynamickú pamäť, mala by mať:

1. deštruktor,
2. kopírovací konštruktor,
3. kopírovací operátor priradenia.

Toto sa nazýva **pravidlo troch**.

---

## Bezpečnejšia trieda dynamického poľa

```cpp
#include <iostream>

class IntArray
{
private:
    int *data;
    int size;

public:
    IntArray(int size)
    {
        this->size = size;
        data = new int[size];

        for (int i = 0; i < size; i++)
        {
            data[i] = 0;
        }
    }

    IntArray(const IntArray& other)
    {
        size = other.size;
        data = new int[size];

        for (int i = 0; i < size; i++)
        {
            data[i] = other.data[i];
        }
    }

    IntArray& operator=(const IntArray& other)
    {
        if (this != &other)
        {
            delete[] data;

            size = other.size;
            data = new int[size];

            for (int i = 0; i < size; i++)
            {
                data[i] = other.data[i];
            }
        }

        return *this;
    }

    ~IntArray()
    {
        delete[] data;
        data = nullptr;
    }

    int getSize() const
    {
        return size;
    }

    void set(int index, int value)
    {
        if (index >= 0 && index < size)
        {
            data[index] = value;
        }
    }

    int get(int index) const
    {
        if (index >= 0 && index < size)
        {
            return data[index];
        }

        return 0;
    }
};

int main()
{
    IntArray a(3);

    a.set(0, 10);
    a.set(1, 20);
    a.set(2, 30);

    IntArray b = a;

    b.set(0, 100);

    std::cout << "a[0] = " << a.get(0) << std::endl;
    std::cout << "b[0] = " << b.get(0) << std::endl;

    return 0;
}
```

Výstup:

```text
a[0] = 10
b[0] = 100
```

Objekty `a` a `b` majú vlastnú pamäť, preto zmena v `b` nezmení `a`.

---

## Moderná poznámka

V modernom C++ by sa namiesto vlastnej triedy dynamického poľa často použil:

```cpp
std::vector<int>
```

Príklad:

```cpp
#include <iostream>
#include <vector>

int main()
{
    std::vector<int> numbers;

    numbers.push_back(10);
    numbers.push_back(20);
    numbers.push_back(30);

    for (int number : numbers)
    {
        std::cout << number << " ";
    }

    return 0;
}
```

Výstup:

```text
10 20 30
```

`std::vector` si dynamickú pamäť spravuje sám.

## 11. Virtuálne funkcie

Virtuálna funkcia je metóda triedy, ktorá môže byť prepísaná v odvodenej triede a volaná polymorfne cez smerník alebo referenciu na základnú triedu.

Používa sa pri dedičnosti.

---

## Príklad bez virtuálnej funkcie

```cpp
#include <iostream>

class Animal
{
public:
    void speak()
    {
        std::cout << "Animal sound" << std::endl;
    }
};

class Dog : public Animal
{
public:
    void speak()
    {
        std::cout << "Woof" << std::endl;
    }
};

int main()
{
    Animal *animal = new Dog();

    animal->speak();

    delete animal;
    animal = nullptr;

    return 0;
}
```

Výstup:

```text
Animal sound
```

Aj keď objekt je v skutočnosti `Dog`, volá sa metóda podľa typu smerníka, teda `Animal`.

---

## Príklad s virtuálnou funkciou

```cpp
#include <iostream>

class Animal
{
public:
    virtual void speak()
    {
        std::cout << "Animal sound" << std::endl;
    }

    virtual ~Animal()
    {
    }
};

class Dog : public Animal
{
public:
    void speak() override
    {
        std::cout << "Woof" << std::endl;
    }
};

int main()
{
    Animal *animal = new Dog();

    animal->speak();

    delete animal;
    animal = nullptr;

    return 0;
}
```

Výstup:

```text
Woof
```

Vďaka `virtual` sa zavolá metóda podľa skutočného typu objektu, teda `Dog`.

---

## Virtuálny deštruktor

Ak trieda obsahuje virtuálne funkcie a bude sa používať polymorfne, mala by mať virtuálny deštruktor.

```cpp
virtual ~Animal()
{
}
```

Dôvod:

Ak mažeme objekt odvodenej triedy cez smerník na základnú triedu, musí sa správne zavolať aj deštruktor odvodenej triedy.

---

## Problém bez virtuálneho deštruktora

```cpp
#include <iostream>

class Base
{
public:
    ~Base()
    {
        std::cout << "Destruktor Base" << std::endl;
    }
};

class Derived : public Base
{
public:
    ~Derived()
    {
        std::cout << "Destruktor Derived" << std::endl;
    }
};

int main()
{
    Base *object = new Derived();

    delete object;

    return 0;
}
```

Toto je problémové, pretože pri mazaní cez smerník na `Base` nemusí byť správne zavolaný deštruktor `Derived`.

---

## Správne s virtuálnym deštruktorom

```cpp
#include <iostream>

class Base
{
public:
    virtual ~Base()
    {
        std::cout << "Destruktor Base" << std::endl;
    }
};

class Derived : public Base
{
public:
    ~Derived() override
    {
        std::cout << "Destruktor Derived" << std::endl;
    }
};

int main()
{
    Base *object = new Derived();

    delete object;

    return 0;
}
```

Výstup:

```text
Destruktor Derived
Destruktor Base
```

Najprv sa zavolá deštruktor odvodenej triedy a potom základnej triedy.

---

## Čistá virtuálna funkcia

Čistá virtuálna funkcia je funkcia bez implementácie v základnej triede.

```cpp
virtual void speak() = 0;
```

Trieda s aspoň jednou čistou virtuálnou funkciou je abstraktná trieda.

Z takej triedy nemožno vytvoriť objekt priamo.

---

## Príklad abstraktnej triedy

```cpp
#include <iostream>

class Shape
{
public:
    virtual double area() const = 0;

    virtual ~Shape()
    {
    }
};

class Rectangle : public Shape
{
private:
    double width;
    double height;

public:
    Rectangle(double width, double height)
    {
        this->width = width;
        this->height = height;
    }

    double area() const override
    {
        return width * height;
    }
};

int main()
{
    Shape *shape = new Rectangle(5.0, 3.0);

    std::cout << "Obsah: " << shape->area() << std::endl;

    delete shape;
    shape = nullptr;

    return 0;
}
```

Výstup:

```text
Obsah: 15
```

## Súhrnný príklad

Tento príklad kombinuje dynamické objekty, virtuálne funkcie a virtuálny deštruktor.

```cpp
#include <iostream>
#include <string>

class Employee
{
protected:
    std::string name;

public:
    Employee(const std::string& name)
    {
        this->name = name;
        std::cout << "Konstruktor Employee: " << name << std::endl;
    }

    virtual void print() const
    {
        std::cout << "Zamestnanec: " << name << std::endl;
    }

    virtual ~Employee()
    {
        std::cout << "Destruktor Employee: " << name << std::endl;
    }
};

class Programmer : public Employee
{
public:
    Programmer(const std::string& name)
        : Employee(name)
    {
        std::cout << "Konstruktor Programmer" << std::endl;
    }

    void print() const override
    {
        std::cout << "Programator: " << name << std::endl;
    }

    ~Programmer() override
    {
        std::cout << "Destruktor Programmer" << std::endl;
    }
};

int main()
{
    Employee *employee = new Programmer("Juraj");

    employee->print();

    delete employee;
    employee = nullptr;

    return 0;
}
```

Možný výstup:

```text
Konstruktor Employee: Juraj
Konstruktor Programmer
Programator: Juraj
Destruktor Programmer
Destruktor Employee: Juraj
```

## Krátke zhrnutie

| Pojem | Význam |
|---|---|
| smerník | premenná obsahujúca adresu |
| `&` | získanie adresy premennej |
| `*` | dereferencovanie smerníka |
| `nullptr` | smerník nikam neukazuje |
| dynamický údaj | údaj vytvorený počas behu programu |
| `new` | pridelenie dynamickej pamäte |
| `delete` | uvoľnenie jedného dynamického objektu |
| `new[]` | pridelenie dynamického poľa |
| `delete[]` | uvoľnenie dynamického poľa |
| memory leak | diera v pamäti, neuvoľnená dynamická pamäť |
| dangling pointer | vystrčený smerník na neplatnú pamäť |
| konštruktor | metóda volaná pri vytvorení objektu |
| deštruktor | metóda volaná pri zániku objektu |
| dynamické pole ako trieda | trieda spravujúca pole vytvorené cez `new[]` |
| virtuálna funkcia | funkcia volaná podľa skutočného typu objektu |
| virtuálny deštruktor | potrebný pri polymorfnom mazaní objektov |

## Mini odpoveď vhodná na skúšku

Smerník v C++ je premenná, ktorá obsahuje adresu inej premennej alebo objektu. Deklaruje sa napríklad ako `int *p`. Operátor `&` slúži na získanie adresy a operátor `*` na prístup k hodnote, na ktorú smerník ukazuje. Dynamický údaj je údaj vytvorený počas behu programu v dynamickej pamäti. V C++ sa dynamická pamäť prideľuje pomocou `new` a uvoľňuje pomocou `delete`; pri dynamických poliach sa používa `new[]` a `delete[]`. Ak program pamäť neuvoľní alebo stratí jej adresu, vzniká diera v pamäti, teda memory leak. Vystrčený smerník je smerník, ktorý ukazuje na neplatnú alebo uvoľnenú pamäť. Pri dynamicky vytvorených objektoch sa po `new` zavolá konštruktor a pri `delete` deštruktor. Dynamické pole možno zabaliť do triedy, ktorá pridelí pamäť v konštruktore a uvoľní ju v deštruktore. Virtuálne funkcie umožňujú polymorfizmus, teda volanie metódy podľa skutočného typu objektu. Pri triedach používaných polymorfne je dôležité mať virtuálny deštruktor.
